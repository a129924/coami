# Companion flow baseline — 需求邊界

## Goal

以精簡文件描述 Coami 預期的兒童陪伴對話流程，讓後續實驗能逐步驗證，而不把未驗證的流程當成已完成能力。

## Success criteria

- 讀者能從一張圖追蹤文字輸入、Companion 回答或追問、Parent／Safety 交接與輸出把關。
- 文件區分產品意圖、既有實驗證據和待驗證假設；下一個文字實驗有明確問題、程序、預期證據和決策標準。
- 情境用語適合幼兒，保留照顧者的決策與接管責任，不記錄私人家庭背景。

## Scope

本 topic 只建立產品摘要、概念流程圖與尚未執行的文字實驗提案。語音和裝置只作為長期產品的外圍邊界；Companion 是本次主要描述路徑，Parent／Safety 只描述交接。

## Non-goals

不執行 POC、不驗證 Jev 或 LLM 效果、不鎖定服務切分、持久記憶、政策閾值或正式通訊契約，不修改 production source、裝置程式或 release 資料。
