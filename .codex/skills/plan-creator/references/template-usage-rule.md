# Template Usage Rule

Rules for using and completing the canonical topic-plan template.

- Start from `templates/topic-plan-template.md` rather than drafting a plan from scratch.
- Replace every prompt with an explicit repository-specific answer.
- Delete irrelevant prompt text; do not leave template scaffolding in the final topic plan.
- Do not add sections that are not part of the canonical template without justification.
- Do not omit required sections even when they appear not to apply; instead write an explicit `not applicable` or `none` statement.
