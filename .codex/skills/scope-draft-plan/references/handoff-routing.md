# Advisory handoff routing

Use these suggestions only after producing a Draft Plan. They are conditional,
non-binding guidance: do not invoke a skill, dispatch an agent, create an
artifact, or require the human to follow a route.

| Condition after scope convergence | May suggest | Reason |
| --- | --- | --- |
| Business intent is still contradictory, unmeasurable, or blocked | `business-intent-alignment` | It can establish a measurable requirements baseline. |
| A requirements baseline is frozen and technical realization needs analysis | `business-to-technical-translation` | It can translate the baseline into technical constraints and work. |
| A technical specification is frozen and a repo-visible topic contract is needed | `plan-creator` | It can author the topic plan. |
| The approved Mission needs a Python-specific implementation contract | `python-plan-authoring` | It can plan Python implementation within the approved boundary. |

If no condition applies, state that no next step is required from this skill.
Never imply that a suggestion grants approval, changes ownership, or starts the
suggested workflow. Stop after presenting the advice.
